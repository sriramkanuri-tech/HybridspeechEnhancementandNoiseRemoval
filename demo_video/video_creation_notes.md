# Video Creation Notes

## Files
- `Speech_Enhancement_Demo.mp4` - final silent demonstration video
- `video_thumbnail.png` - frame captured from the completed video

## Recording method
The final video was generated using a Python/ImageIO pipeline with Pillow frame rendering. Genuine application screenshots and genuine project result images were used. The video contains no audio stream.

## Demonstrated features
- Project title screen
- Actual Speech Enhancement and Noise Removal application window
- Device and processing-mode selection interface
- Processing workflow captions for capture and enhancement
- Genuine waveform comparison from `results/waveform_white.png`
- Genuine SNR comparison from `results/snr_comparison.png`
- Closing summary screen

## Features not fully demonstrated
- Live microphone Start/Stop interaction was not performed in the final recording because reliable hardware capture could not be automated safely.
- Virtual microphone pairing in Google Meet, Teams, and Zoom was not performed and remains unverified.
- PDF report navigation and output folder browsing were not included to keep the video under 60 seconds.

## Verified video properties
- Duration: 46.0 seconds
- Resolution: 1920 x 1080
- Frame rate: 30 FPS
- Audio stream: none
- Codec: H.264 via libx264
- Aspect ratio: 16:9

## Notes
All on-screen application content is from the real application interface. Metrics and graphs shown are generated by the project. No metrics or processing results were fabricated.
